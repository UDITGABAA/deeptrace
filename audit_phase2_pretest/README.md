# DeepTrace pre-test audit (read-only)

Date: 2026-08-16  
Scope: code, configuration, checkpoint metadata, existing reports, and on-disk dataset structure only. No model inference, training, downloads, file modification, or new experiment was performed.

## Decision

Do **not** run or report the requested Phase 2 follow-up experiments until the P0 items below are corrected and their outputs are regenerated. The current artifacts demonstrate strong in-domain separation for the Kaggle StyleGAN-vs-FFHQ setting, but they do not yet support the present claims about calibration, Grad-CAM localization, fair baselines, or non-StyleGAN generalization.

## P0 — must fix before any new results are trusted

| Finding | Evidence from the workspace | Why it matters | Required preflight fix |
|---|---|---|---|
| External-folder evaluations double every image on Windows. | `GenericFolderDataset` loops over both `Real`/`real` and `Fake`/`fake` (`scripts/evaluate_research_benchmarks.py:59-64`). Windows resolves each case variant to the same folder. On disk, `_new_dataset_extracted/Test` contains 5,413 real + 5,492 fake = **10,905** images, but the saved JSON reports **21,810**; `test_data` contains 49 real + 50 fake = **99**, but the JSON reports **198**. | The point estimates happen to be unchanged by exact duplication, but every reported sample count, confusion-matrix count, standard error, bootstrap CI, and any statistical comparison based on these results is invalid. | Enumerate each physical class directory exactly once; save a manifest containing relative path, label, and SHA-256 (or an immutable path list). Regenerate all external-dataset metrics and figures after confirming `N=10,905` and `N=99`. |
| The existing Grad-CAM is not computed on the same input/prediction protocol as the displayed verdict. | Normal image inference uses DCT, calibrated probabilities, and two-view TTA (`inference/pipeline.py:159-213`). Decide whether the map is for the original view or an aggregation of both TTA views, record that choice, and verify the CAM-pass probability matches the reported pass. |
| The written Grad-CAM description contradicts its own saved result. | The submission report calls `tpdne_0.jpg` 98.2% confident. Do not use qualitative localization language before the 20–30-per-class analysis is complete. |
| Calibration is currently reported as good even though the saved metrics say it is worse. | For the V2 evaluation, raw vs calibrated validation Brier is 0.002789 vs 0.005355 and raw vs calibrated ECE is 0.00255 vs 0.04770. | The temperature sidecar used for V2 evaluation is not version-bound to the V2 checkpoint. | Evaluation loads `checkpoints/v2_clip_finetune/best_model.pth` but explicitly reads `checkpoints/kaggle_realfake/calibration.json` (`scripts/evaluate_research_benchmarks.py:203-220`). This affects reported calibrated accuracy, confusion matrix, Brier/ECE, and the current Grad-CAM report threshold. | Store calibration beside the exact checkpoint, with checkpoint hash, validation-manifest hash, fitted temperature, threshold-selection rule, and evaluation protocol. | The planned external-data loaders do not create defensible splits. | FF++ appends all originals before manipulations then slices the ordered list (`datasets/faceforensics.py:32-54`). Celeb-DF does the same for non-official train/validation splits (`datasets/celebdf.py:25-57`). DFDC slices metadata insertion order (`datasets/dfdc.py:48-64`). ## Existing numbers that may be kept, but only with the stated caveats

- The Kaggle folder/CSV split has no overlapping CSV `id` or `original_path` across train, validation, and test. The base documented split is 100,000 / 20,000 / 20,000, balanced by folder class. This supports an in-domain result, but it does **not** establish general deepfake detection.
- The existing 0.99995-ish Kaggle test AUC measures discrimination between FFHQ-like reals and the dataset's StyleGAN fakes under the chosen preprocessing. It should be called **in-domain StyleGAN-vs-FFHQ performance**.
- The existing `_new_dataset` and `test_data` AUC point estimates are not invalidated by exact duplicate rows, but their reported N must be halved and their uncertainty recalculated. They remain unsuitable as a documented non-StyleGAN claim until provenance is established.
- The existing MesoNet result is useful as a **preliminary 5-epoch implementation baseline**, not as a paper-faithful or capacity-matched comparison.

## Recommended execution order after the preflight fixes

1. Create versioned manifests and repair the evaluator's one-directory-per-class logic; regenerate only existing Kaggle/external summaries to establish a clean reference.
2. Refit V2 temperature scaling on the V2 validation manifest; freeze it; produce one internally consistent Table II and primary confusion matrix on V2 test.
3. Repair Grad-CAM fidelity, then export the requested one real/one fake overlays with machine-readable provenance. Only after that run the 20–30/class localization study with a predeclared localization rubric.
4. Establish external dataset provenance and official/group-safe split before running the zero-shot generalization test. Report video-level AUC, N, 95% CI, and per-manipulation breakdown.
5. Run the documented MesoNet protocol with the same manifest and evaluation code; use multiple seeds if feasible.
6. Update related work and limitations **after** the new results. The present limitations text should not attribute the `_new_dataset` collapse to compression: the prior compression stress test did not establish that explanation.

## Safe report language until then

> DeepTrace achieves near-perfect discrimination on the evaluated Kaggle split, whose fake class is StyleGAN-derived and whose real class is FFHQ/Flickr-derived. This in-domain result should not yet be interpreted as broad deepfake-detection capability. Existing external evaluations are exploratory because one test set lacks verified label provenance and the documented video-dataset protocols have not yet been implemented. Calibration, explainability, baseline fairness, and non-StyleGAN generalization require the pre-registered follow-up evaluations described above.
